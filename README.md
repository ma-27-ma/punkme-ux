# PunkMe 🎸

PunkMe is a UX/UI design project focused on creating a digital experience, content, news and sales application inspired by punk music and its derivatives.

## About the project

The project explores how visual identity, usability and user experience can work together to create an engaging digital product.

The interface was designed in Figma, with a focus on:

- User experience
- Visual identity
- Interface design
- Navigation and usability
- Interactive prototyping
